# PART 3 — TAXONOMY, COGNITIVE DEMAND, AND DIFFICULTY

## 3.1 Bloom's Revised Taxonomy

Implement the six cognitive levels:

1. **C1 — Remember:** Retrieve facts, terms, definitions, and basic information.
2. **C2 — Understand:** Explain, summarize, classify, interpret, and exemplify.
3. **C3 — Apply:** Use concepts, rules, procedures, or knowledge in a situation.
4. **C4 — Analyze:** Differentiate, organize, compare, infer, and identify relationships.
5. **C5 — Evaluate:** Judge, justify, critique, and make evidence-based decisions.
6. **C6 — Create:** Design, formulate, produce, construct, or develop a solution.

For every generated question, store:

- Selected Bloom level.
- Cognitive operation being assessed.
- Evidence that the question requires that operation.
- Expected student response.
- Rationale for the classification.
- Confidence or review status.

Do not classify a question as C4, C5, or C6 merely because it contains a long text or difficult vocabulary.

## 3.2 SOLO Taxonomy

Implement five SOLO levels:

1. **Prestructural:** The response does not demonstrate a relevant understanding.
2. **Unistructural:** The response uses one relevant aspect.
3. **Multistructural:** The response identifies several relevant aspects without integrating them.
4. **Relational:** The response connects multiple aspects into a coherent explanation.
5. **Extended Abstract:** The response generalizes, theorizes, or transfers understanding to new contexts.

Use these levels as a learning-design and response-quality framework. They are not automatically interchangeable with Bloom's levels.

For each question, provide a rationale explaining the expected evidence of learning at the selected SOLO level.

Where appropriate, provide SOLO-based scoring descriptors for open-ended questions.

## 3.3 Difficulty Classification

Implement a separate difficulty selector:

- Very Easy.
- Easy.
- Medium.
- Difficult.
- Very Difficult.

Also provide a familiar four-category view:

- Mudah.
- Sedang.
- Sulit.
- Sangat Sulit.

The difficulty level must be configurable and mapped transparently to the selected labels.

## 3.4 LOTS and HOTS

Provide a separate cognitive-demand classification:

- LOTS — Lower Order Thinking Skills.
- HOTS — Higher Order Thinking Skills.
- Mixed or context-dependent, when appropriate.

Do not equate HOTS with “difficult” automatically. A difficult recall question can still be LOTS, while a well-scaffolded analysis question may be HOTS without excessive reading difficulty.

## 3.5 Taxonomy Mapping Interface

Create a matrix that allows users to select:

- Bloom level.
- SOLO level.

Treat these as user-defined examples, not mandatory universal distributions.

## 10.3 Multiple-Choice Quality Rules

For single-answer multiple-choice questions:

- Provide the requested number of options; default to four when configured.
- Ensure exactly one defensible correct answer unless the selected format explicitly allows multiple correct answers.
- Use plausible distractors based on realistic misconceptions.
- Avoid distractors that are obviously absurd.
- Avoid grammatical cues that reveal the answer.
- Avoid unnecessary repeated words or phrases across options.
- Avoid duplicated answer options.
- Keep options relatively similar in length and grammatical structure where feasible.
- Do not force identical option lengths when doing so reduces accuracy or clarity.
- Ensure options are parallel in form whenever appropriate.
- Avoid overlapping answer choices.
- Avoid ambiguity and unintended multiple correct answers.
- Avoid “all of the above” or “none of the above” unless explicitly justified.
- Avoid trick wording, unnecessary negative phrasing, and irrelevant complexity.
- Do not allow the correct answer to stand out consistently by being longer, more specific, or stylistically different.
- Keep the question independent of accidental clues from other questions.
- Verify the answer key against the question and stimulus.
- Randomize option order only if the answer-key mapping is updated correctly.

## 10.4 Answer-Key Integrity

For every objective question:

1. Validate that the answer key refers to an existing option or valid response.
2. Check that the explanation supports the keyed answer.
3. Verify that the question does not contradict its source stimulus.
4. Flag potentially ambiguous items.
5. Identify multiple plausible correct answers when a single answer is required.
6. Preserve answer-key integrity after option randomization.
7. Record changes to correct answers in version history.

For open-ended questions, provide scoring criteria rather than inventing a single fixed answer where multiple valid responses exist.

## 10.5 Anti-Repetition Rules Within an Assessment

Check for:

- Repeated question wording.
- Duplicate stems.
- Repeated scenarios.
- Reused answer patterns.
- Repeated distractors.
- Repeated tested concepts without a justified reason.
- Excessive overlap between learning objectives.
- Repeated source passages.
- Unintended answer clues between questions.

When repetition is detected, explain the similarity and provide revision options.

Allow intentional repetition for practice, spaced retrieval, or parallel testing when explicitly requested.

## 11.2 Strict Stimulus Limit

Implement the following mandatory rule:

**One shared dialogue, text, passage, case, or stimulus group may support a maximum of five questions. The recommended range is three to five questions when appropriate.**

Rules:

1. One stimulus group may contain 1–5 questions.
2. When a passage is intended to support multiple questions, recommend 3–5 items if educationally suitable.
3. Never exceed five linked questions for the same stimulus group.
4. Count linked questions automatically.
5. Block attempts to attach a sixth question to that group.
6. Explain the limit and offer the option to create a new stimulus group.
7. Do not bypass the limit through duplicate stimulus IDs or hidden links.
8. Preserve group relationships during editing, importing, copying, and exporting.
9. Allow a separate group to use the same source material only when permitted and when the new group is clearly identified.
10. Recheck the limit before final export and publication.

The system must validate the rule at both the interface and server/database level.

## 11.3 Stimulus Quality Checks

- Relevance to the objective.
- Appropriate reading or listening complexity.
- Source integrity.
- Sufficient information to answer linked questions.
- Absence of accidental answer leakage.
- Language accuracy.
- Copyright and usage considerations.
- Accessibility.
- Question count.
- Whether the stimulus supports the intended cognitive level.

8. Its limitations are disclosed.
9. It does not falsely report completion.
